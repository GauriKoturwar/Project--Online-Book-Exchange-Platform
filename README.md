# 📚 SMART-BookDeals – Online Book Exchange Platform
## 📌 Project Overview
SMART-BookDeals is a web-based Online Book Exchange Platform developed to make buying, selling, donating, and exchanging books easier and more affordable.
The platform connects students and book lovers, allowing them to reuse books, reduce educational expenses, and promote a sustainable book-sharing community.

## 🎯 Objectives
- To provide an online platform for buying and selling books.
- To encourage book donation and reuse.
- To make educational books affordable and accessible.
- To connect users who want to exchange books.
- To reduce book wastage and promote sustainability.

## ✨ Key Features
- **User Registration and Login:** Secure user authentication.
- **Buy Books:** Browse and find available books.
- **Sell Books:** List books for sale.
- **Donate Books:** Allow users to donate books.
- **Exchange Books:** Send and manage book exchange requests.
- **My Books:** Manage personal book listings.
- **Search Books:** Find books based on availability and details.
- **User Dashboard:** Manage user activities.

## ⚙️ Installation and Setup

Follow these steps to run the project locally:

1. Download and install [XAMPP](https://www.apachefriends.org/).
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the SMART-BookDeals project folder into the `htdocs` directory.
4. Open phpMyAdmin using `http://localhost/phpmyadmin`.
5. Create a database named `book_exchangedb`.
6. Import the provided `book_exchangedb.sql` database file.
7. Configure your database connection in `includes/db.php`.
8. Open your browser and visit:

   `http://localhost/SMART-BookDeals/`
